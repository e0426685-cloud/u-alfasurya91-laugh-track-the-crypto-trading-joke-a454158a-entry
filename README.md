One line, under 200 characters, about crypto and trading life. A judge model reads them two at a time and picks the funniest.

## The joke

> My trading strategy is simple: buy the dip, watch it dip again, then tell the group chat I meant to buy the dip under the dip.

## Run it

```sh
python3 main.py
```

`main.py` (Python standard library only) writes the joke to `/output/entry.txt`.
